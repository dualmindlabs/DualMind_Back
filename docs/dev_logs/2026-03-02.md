# Development Log - 2026-03-02

## 1. CI/CD Azure Deployment Fix
- Fixed the GitHub Actions deployment workflow (`.github/workflows/master_dualmind-arena.yml`).
- Switched from building the `.sln` and using OIDC to using `dotnet publish` and the **Publish Profile** secret (`AZURE_PUBLISH_PROFILE`).
- Fixed MSB1008 error by wrapping the output path in quotes (`"${{env.DOTNET_ROOT}}/myapp"`).

## 2. Gamified Energy System (Clash Royale / Duolingo style)
- **Database**:
  - Added `energy_balance` (default 20), `last_energy_refill_date`, and `has_claimed_demo_video` to `public.users`.
  - Created the atomic `consume_energy` RPC function to prevent race conditions during battles.
- **Backend Services**:
  - Created `IEnergyService` and `EnergyService`.
  - Added `ConsumeBattleEnergyAsync`, `RefillDailyEnergyAsync`, and `ClaimVideoEnergyAsync`.
  - Integrated daily refill (+2 bonus) into `UserSyncService.EnsureUserExistsAsync` on login.
- **Controllers**:
  - Created `EnergyController` with GET `/api/energy/balance` and POST `/api/energy/claim-video`.
  - Updated `ArenaController` to consume 3 energy per battle, returning `402 Payment Required` if the user is out of energy.
- **Feature Flag**:
  - Wrapped the entire energy logic in the `energy_system_enabled` feature flag so it doesn't break production until the frontend is ready.
- **Git**:
  - Saved and pushed these changes to a separate branch: `feature/energy-system`.
